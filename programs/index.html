Programs

These are some scripts and tools we have written that we hope will be useful. If you discover any bugs or have any questions, please get in touch by email or on GitHub.

  • PASCal Python

    A new, upgraded open-source version of the original PASCal web tool for calculating the principal strains, and thus thermal expansivities/hydrostatic compressibilities/electrochemical strains, from lattice parameter data. This is now a Python package and can be used offline in Jupyter notebooks! Contributions are welcome via the GitHub repository.

  • PASCal

    The original web tool for calculating the principal strains, and thus thermal expansivities/hydrostatic compressibilities, from lattice parameter data. See the published paper.

  • PASCal Indicatrix Plotter

    Scripts for creating indicatrix plots from PASCal output.

  • Coordination Polyhedra for PyMOL

    A Python script that draws coordination polyhedra in PyMOL. The zip file contains instructions, the script and an example PDB file.
